# AR100 退役参考

`flash-reference.json` 来自 `9f30c114:scripts/flash-ar100.py`，原文件
SHA-256 为 `3ff3d64d70a84335db8790530c443c89326eca661ef27649c456c6c6e9aeaee7`。
生成时执行原脚本，仅把 `/dev/mem` 的 open 重定向为私有稀疏普通文件
的 `r+b`（不截断），使用原 mmap、原地址和原函数。无实际设备访问。
SRAM 0x40000–0x54000 和复位寄存器初值均为 0xa5；固件第 i 字节
为 `(i * 37 + 11) % 256`。记录完整 SRAM SHA-256、最终复位字节和原
输出，覆盖全部原操作模式与 1/65536 字节边界。

常规回归只读取固定 JSON，不执行 Python。可选性能基准从固定 Git
历史提取原脚本并使用 Python 运行，以同样的普通文件映射对照；这不
属于刷写运行依赖。该历史必须可访问，否则基准失败而非跳过。
原 Python 没有读回校验和独占锁；新实现具备这两项额外工作，因此
耗时不是功能工作量完全相同的比较。真实 A64 板卡验收仍未完成。
