## 目标与范围

最终目标保持 active：使用 Node.js 26／TypeScript、专用数学库及必要时
Rust 数学库，全面替代所有 Python，集成完整原生 Moonraker，并将任意宏
转换为消费级受控操作。无 Python 的构建、安装、启动、打印、维护、升级、
恢复和日常测试均须闭合。现有 C MCU 固件及 C 运动内核可保留。

当前仅适配 **ANYRAID Cycnumbris 500 系列**。完整 Moonraker 是首要功能
主线，其他机型全部最后处理。系列内板卡、外设和配置差异须取得资料后
核验，不假定所有机器相同。Rust 只用于已证实的精度或性能缺口，
不通过换库掩盖数值异常；数学库选择服从明确误差预算及目标板结果。

本次调整执行方式：从最终交付物确定用户路径，再识别依赖模块。
以可审阅、可复现的 Klipper＋Moonraker 候选包和当前系列实机准入为近期
目标；模块数量、提交数量及模拟测试数量不作为整体完成率。
